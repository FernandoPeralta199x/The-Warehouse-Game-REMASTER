# Roadmap técnico

## Sprint 0 — Fundação

- abrir no Unity 6.3 LTS;
- executar setup automático;
- corrigir qualquer warning de pacote;
- rodar testes;
- versionar projeto.

## Sprint 1 — Puzzle vertical slice

- Tilemap visual;
- movimento animado;
- sensor e porta;
- Undo visual;
- áudio P0;
- uma fase completa.

## Sprint 2 — Corrida vertical slice

- pista com colisores;
- câmera Cinemachine;
- drift visual;
- Power Ups;
- HUD de volta/posição;
- IA simples;
- telemetria de tempo.

## Sprint 3 — Ferramentas

- editor de fases;
- validação automática de mapas;
- catálogo de áudio;
- save versionado;
- seleção de fases.

## Sprint 4 — Conteúdo

- Setores 01 e 02;
- Oficina N-8;
- três corridas;
- narrativa inicial;
- medalhas.

## Gates

Não avançar sem:

```text
compilação limpa;
testes verdes;
sem assets sem licença;
controle funcionando em teclado e gamepad;
save recuperável;
profiling básico;
```
