# Setup técnico

## Requisitos

- Unity Hub;
- Unity 6.3 LTS, preferencialmente o patch mais recente da família 6.3;
- módulo Windows Build Support para a primeira entrega;
- IDE com suporte a C# e analyzers;
- Git e Git LFS para áudio e arte binária.

## Primeira abertura

1. Abra a pasta raiz pelo Unity Hub.
2. Aguarde a resolução do Input System.
3. Aceite a ativação do novo Input System quando solicitado.
4. Execute o gerador de protótipos no menu Tools > TW08.
5. Execute o validador.
6. Execute todos os testes.

## Arquivos não versionados

`Library`, `Logs`, `Temp`, `Obj` e `UserSettings` são locais e regeneráveis.
