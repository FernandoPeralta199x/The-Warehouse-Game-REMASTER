# Referências técnicas pesquisadas

Fontes primárias e oficiais usadas para orientar esta base:

1. **Unity 6 release support** — Unity 6.3 é a versão LTS atual e possui suporte de longo prazo até dezembro de 2027.
   - https://unity.com/releases/unity-6/support

2. **ScriptableObject** — contêiner de dados independente de instâncias e adequado para assets de configuração reutilizáveis.
   - https://docs.unity3d.com/6000.1/Documentation/Manual/class-ScriptableObject.html

3. **Input System** — sistema extensível para teclado, gamepad e outros dispositivos; versão 1.17 publicada para Unity 6.
   - https://docs.unity3d.com/6000.0/Manual/com.unity.inputsystem.html

4. **Cinemachine** — ferramentas de câmera; linha 3.1 publicada para Unity 6.
   - https://docs.unity3d.com/6000.0/Manual/com.unity.cinemachine.html

5. **Unity Test Framework** — execução de testes Edit Mode e Play Mode.
   - https://docs.unity3d.com/6000.0/Manual/com.unity.test-framework.html

6. **Tilemap** — sistema de tiles associado a Grid, Tilemap Renderer e Tilemap Collider 2D.
   - https://docs.unity3d.com/Manual/class-Tilemap.html

## Referência de gênero

O modo corrida usa apenas princípios abstratos do gênero arcade/kart: drift, boost, itens, checkpoints e recuperação por posição. Nenhum código, asset, pista, personagem ou item de franquia externa foi usado.
